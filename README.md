# 使用说明（demo 版）

## 现在有什么

一个可运行的暖调「年度报告」网页，10 屏：

1. 开场加载（进度条 → 仅你可见）
2. 封面（2026 / 宝贝 你的这一年）
3. 数据（365 天 / 47 次 / 3 次 / 0 次）
4. 年度最幸福瞬间（大图 + 一句话）
5–8. 告白 4 页（内容在 `content.js`，想加多少页加多少条）
9. 结尾（报告结束了）
10. 海报（自动生成，长按保存）

你之前删掉的「总时长 / 关键词 / 第一次 / 年度单曲 / 她的影响力 / 彩蛋」都已移除；「最幸福的瞬间」替代了原来的「年度单曲」。

## 怎么在手机上看

电脑和手机连同一个 WiFi，手机浏览器打开：

```
http://192.168.71.104:8080
```

（这是临时局域网地址，只用于预览。正式版会部署到 GitHub Pages。）

桌面调试快捷键：`↓ / ↑` 翻屏。

## 音乐

`assets/audio/bgm.mp3` 是我用代码合成的 **60 秒卡农（D 大调）八音盒版**（帕赫贝尔原曲已进入公有领域，编曲是我写的，无版权风险）。想换成你们的歌：

1. 把 mp3 放进 `assets/audio/`
2. 改 `content.js` 里的 `song.src`
3. 建议压到 128kbps 以内，文件别超过 1.5MB

右下角有常驻的播放/暂停按钮。

## 怎么改内容

**只改 `content.js`**，其他文件不用碰。

| 字段 | 作用 |
|---|---|
| `name` | 她的称呼，封面和海报都会用 |
| `stats.items` | 数据屏的 4 组数字，`value` 是数字，会滚动 |
| `happiest` | 最幸福瞬间：图片路径、标签、那句话、备注 |
| `letters` | 告白页，数组，每项一屏，`body` 是段落数组 |
| `future.items` | 2027 待办清单 |
| `ending` | 结尾两行字 |
| `poster` | 海报：`img` 可选（填了就用照片做背景）、`line` 正文、`sign` 落款 |
| `song.src` | 填 mp3 路径就出现音乐按钮，留空则隐藏 |

照片放 `assets/img/`，建议 3:4 竖图，长边 1400 像素以内。

## 调试参数

- `?s=3` 直接跳到第 3 屏（0 开始数）
- `?noanim=1` 关闭所有动画（截图/核对排版用）
- `?fast=1` 跳过开场加载

## 文案长度建议

- 告白每页：**2–3 段，每段不超过 40 字**。超过就会顶出屏幕。
- 数据屏：4 组正好，第 5 组要删掉一行。
